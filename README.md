# 🧩 Java Maze Game

## 📌 Description

This is a maze game developed in Java to run in the terminal.

The player's objective is to find the maze exit before running out of moves.

---

## 🎮 How to Play

* `@` → Player
* `S` → Exit
* `#` → Wall
* `.` → Path
* `*` → Item

### Controls

* W → Move Up
* A → Move Left
* S → Move Down
* D → Move Right

---

## 🚀 Technologies

* Java
* Object-Oriented Programming
* Terminal Interface

---

## ✨ Features

* Maze navigation
* Collectible items
* Limited movement system
* Win and lose conditions
* Terminal-based gameplay

---

## ▶️ Running the Project

1. Clone the repository
2. Open the project in your preferred Java IDE
3. Run the `Main` class
